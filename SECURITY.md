# Security policy

Please do not disclose a suspected vulnerability in a public issue, pull
request, discussion, or chat transcript. Use GitHub's private vulnerability
reporting for this repository when it is enabled. If that channel is not
available, contact a CanonFlow-Assay organization administrator privately
through GitHub and include a minimal reproduction and impact assessment.

This early project has no released package or application. Security review and
mobile-device testing remain necessary even when profile checks pass.
