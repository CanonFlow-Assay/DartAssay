# reference_order_app — M1 placeholder

This directory is reserved for the M1 offline Flutter reference application.
It is intentionally not a Flutter project while Human Gate A is pending.

After approval, it will demonstrate an order draft with typed values
`OrderDraft`, `OrderLine`, `ItemName`, `Quantity`, `Money`, `OrderFault`, and
`ReadyOrder`, plus pure validation, Flutter widget states, and one critical
integration journey. It will not access the network, storage, database, clock,
or platform plugins.

The acceptance contract is at
[`docs/REFERENCE-ORDER-APP-ACCEPTANCE.md`](../../docs/REFERENCE-ORDER-APP-ACCEPTANCE.md).
